# ضت (Dht) – مكتبة تشفير الصور والفيديو والصوت

مكتبة C++ مفتوحة المصدر لتشفير الملفات الوسائطية باستخدام AES-256-GCM وضغط XZ.

## الميزات
- تشفير وفك تشفير الصور (PNG, JPEG, BMP)
- تشفير وفك تشفير الفيديو (MP4, AVI, MKV)
- تشفير وفك تشفير الصوت (M4A, MP3, WAV)
- ضغط XZ لتقليل حجم الملفات
- جميع العمليات في الذاكرة (لا ملفات مؤقتة)
- كلمة مرور بطول 32 حرفاً كحد أدنى
- لا يتم تخزين أي أثر لكلمة المرور في الملف المشفر

## المتطلبات
C++17
